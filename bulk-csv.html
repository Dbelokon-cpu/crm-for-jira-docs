Bulk actions, import and export

Change many records at once, bring in existing data from a spreadsheet, and take data out.

Bulk actions#

Tick the boxes at the start of rows to select them. Buttons for the actions available in that section appear above the list.

SectionYou can
LeadsAssign, change status, change rating, delete
DealsAssign owner, change stage, delete
Contacts, CompaniesAssign owner, delete
ProductsDelete
TasksAssign, change priority, complete, delete

Deleting asks you to confirm and states how many records will go. Bulk deletion cannot be undone.

Import from CSV#

Press Import CSV on Contacts, Companies, Leads, Deals, Products or Tasks.

  1. In your spreadsheet, make the first row the column names, then export or copy it as CSV text.
  2. Paste the text into the window. It lists the column names it recognises; use those names exactly.
  3. Press Import.

Each row is checked exactly as if you had typed it into the form. A row with, say, an invalid email address is skipped and listed with the reason; the other rows are still imported. Only the name is required.

Example: importing contacts
NameTitleCompanyEmailPhoneTags
Sarah MillerHead of OperationsNorthwind Traderssarah@example.com+1 555 0100partner

The columns it recognises for contacts are Name, Title, Company, Email, Secondary Email, Phone, LinkedIn, Tags and Jira Work Item. A company is matched by name to one that already exists, so import companies first.

Import twice and you get two copies. Import does not look for existing records. Check the result, and use Potential Duplicates if you have to clean up.

Export to CSV#

Press Export CSV on a list. A window shows the data as text: select all (Ctrl+A or Cmd+A), copy, and paste it into a spreadsheet or a file ending in .csv. The export follows your current filters. If rows are selected, you can export just those.

Several report tables have their own Export to CSV button, and Settings can export everything.

The app shows CSV as text, not as a download, because the page it runs in cannot start a file download.
