What is logged

Every change in the app writes one line to the audit trail: who did it, what they did, to which record, and when. Events are of these kinds: Created, Updated, Status changed, Reassigned, Note added, Converted, Merged and Deleted.

An edit lists the fields that changed, with before and after, for example rating: Cold → Hot, amount: 8,000 → 12,000. If many fields changed, the first few are shown with a count of the rest. A change to a field that points at another record, such as the company, is reported as company changed.

Where to see it

  • The Activities section: everything, newest first. Filter by record type (Lead, Contact, Company, Deal, Product, Task) and by event type.
  • A record's Timeline tab: only that record's history.
  • Last activity on a card and Recent Activity on the Dashboard.

Activities can be exported to CSV.

How much is kept

The trail keeps the latest 500 entries. Older ones are removed automatically as new ones arrive, so it is a recent history, not a permanent archive. The Activities section shows the newest 100. Settings shows how many entries are kept right now.

If you need a long-term record of something, put it in a note on the record.
